## Yandex Music (ru.yandex.music)

**Supported versions:** `2026.11.1 #171gpr` `2026.11.2 #172.1gpr`

| Patch | Details |
|---|---|
| **Блокировать аналитику Плюса** | Перенаправляет на localhost хосты событий и привлечения Плюса, а также устаревшие триггеры динамических страниц. API музыки и платежей не затрагиваются. |
| **Настройки Nyandex** | Добавляет страницу «Настройки Nyandex», которая открывается новой строкой вверху настроек приложения. Там же показываются параметры патчей. |
| **Отдельный аккаунт Passport** | Даёт переподписанному приложению собственный тип аккаунта Passport, чтобы Android разрешил создать в нём аккаунт Яндекса, а оригинальные приложения Яндекса сохранили общий. |
| **Отключить Play Billing** | Отключает вызовы Play Billing и Play Core. Покупки становятся недоступны, и ни один платёжный запрос не доходит до Google Play. |
| **Отключить телеметрию** | Отключает адреса и описания сервисов AppsFlyer, AppMetrica, OpenTelemetry и Firebase/Crashlytics. |
| **Подменить заголовок сертификата Firebase** | Передаёт сертификат оригинального приложения в заголовке X-Android-Cert, который использует Firebase Installations, чтобы переподпись APK не ломала Firebase. |
| **Подменить подпись приложения** | Приложение видит свою оригинальную подпись Яндекса, поэтому вход через Яндекс ID и другие проверки подписи работают после переподписи APK в Morphe. Нужен для входа. |
| **Разблокировать Яндекс Плюс** | Принудительно задаёт hasPlus, hasMusicSubscription, serviceAvailable и isChild в DTO музыкальной сессии и профиля Passport. Сервер по-прежнему видит настоящий аккаунт. |
| **Скрыть вкладки нижней панели** | Добавляет на страницу настроек Nyandex переключатели для скрытия вкладок нижней панели (Моя волна, Главная, Подкасты, Концерты, Детям, Коллекция). Применяется после перезапуска. |
| **Тексты песен из LRCLIB** | Тексты песен загружаются только из LRCLIB (lrclib.net), API текстов Яндекса не используется. Текст можно открыть у любого трека; текст следующего трека и скачанных треков загружается заранее и сохраняется для офлайна. Если LRCLIB недоступен, появляется уведомление. |
| **Тема Monet** | Окрашивает карточки, акценты, основную кнопку, кнопку воспроизведения в плеере и кнопки «Моей волны» в цвета обоев Android 12+ (Material You); фон страниц остаётся чёрным. Настройка «Светлая / Тёмная / Системная» продолжает работать. На старых версиях Android цвета остаются стандартными. |
| **Убрать заголовки отслеживания** | Перестаёт добавлять X-Request-Id и идентификаторы устройства Яндекса в запросы Музыки и Плюса. |
| **Чистые ссылки** | Убирает из ссылок «Поделиться» и «Скопировать ссылку» метки utm_* и случайный ref_id, по которому переход по ссылке можно связать с тем, кто ею поделился. Ссылки-приглашения сохраняют invite_id. |
